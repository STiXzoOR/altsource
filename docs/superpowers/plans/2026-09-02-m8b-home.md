# M8b Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the home page inside the Storefront shell: an App Store hero with an information ribbon, Add and Share, Today-style cards for featured apps, snapping shelves, App Store small lockups on desktop and AltStore rows on phones, per-store empty states, and an About section with the website link.

**Architecture:** Four new presentational components (`Ribbon`, `Shelf`, `FeatureCard`, and a reworked `AppRow`/`NewsCard`/`SectionHeader`) carry the App Store measurements as CSS classes in `global.css` so every page reuses them; `index.astro` composes them. The store switch grows a tiny empty-state refresh so filtered lists explain themselves.

**Tech Stack:** Astro 7, Tailwind 4, node:test, Playwright MCP.

**Spec:** `docs/superpowers/specs/2026-09-02-m8-storefront-design.md` (§3.3 radii/motion, §4 store switch effects, §5.1 Home).

## Global Constraints

- Same as M8a: breakpoints `xs 484 / lg 1000 / xl 1260 / 2xl 1580`; gutters 16 / 25 / 40 px exposed as `--gutter`; type through `t-*` utilities; no maintainer links; Hugeicons only; 44 px targets on phones.
- Measurements: ribbon labels 11/600 uppercase, values 22/700 in `--ribbon-value`, 144 px columns on phones; shelves snap with 10 px gap on phones and 20 px from 1000 with a 15 px edge fade and 28×64 arrows; Today cards 3:4, radius 17, 407 px wide on desktop, eyebrow 12/600 white 56 %, title 34/700, app row 48 px icon; Get pill radius 1000, padding 7px 16px, 13/700, key colour at 6 % (hover 10 %, active 7 %); AltStore phone rows 87 px tall, radius 20, tint at 15 %, 59 px icon radius 13, pill 76×30 uppercase 15/700.

    document.documentElement.dataset.store = value;
    for (const b of buttons) b.setAttribute('aria-checked', String(b.dataset.storeSet === value));

  };
  apply(document.documentElement.dataset.store || 'all');
  for (const b of buttons) b.addEventListener('click', () => {

    try { localStorage.setItem('store', value); } catch {}
