# M8c App Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every app its App Store product page on desktop and its AltStore app page on phones: artwork hero with the 194 px icon, information ribbon, snapping screenshot shelf, description, What's New with a Version History sheet, App Privacy-style permission cards, an Information grid, links, "More by" lockups, store-aware Get, and sheets that slide up on iOS's curve.

**Architecture:** Sheet motion becomes one CSS contract (`.sheet`) shared by the action sheet, the version history and the lightbox, with a single dialog script in `Base.astro`. The page renders two heroes (`.apphero` for desktop, `.apphero-phone` for phones) over one shared body; screenshots reuse `Shelf`; permissions and information get App Store card and grid classes.

**Tech Stack:** Astro 7, Tailwind 4, node:test, Playwright MCP.

**Spec:** `docs/superpowers/specs/2026-09-02-m8-storefront-design.md` (§4 install buttons, §5.2 App page, §6 Sheets, §7).

## Global Constraints

- As before: px breakpoints `xs 484 / sm 640 / md 768 / lg 1000 / xl 1260 / 2xl 1580`; gutters through `--gutter`; type through `t-*`; component classes inside `@layer components`; no maintainer links; Hugeicons only; 44 px targets.
- Measurements: desktop hero 286 px, icon 194 px radius 25 % with `2px solid rgba(255,255,255,.3)` and `0 0 30px rgba(0,0,0,.33)`, h1 34/700 `-.02em`, subtitle 17/700 at `rgba(246,246,246,.6)`, price line 13/400; artwork `blur(100px) saturate(1.5)` under `linear-gradient(to bottom, transparent 20%, rgba(0,0,0,.8))`. Ribbon as M8b. Screenshots: phones 184 px columns gap 12 radius 14; desktop 3 / 4 / 5 columns at 1000 / 1260 / 1580, gap 20, radius 12. Sheets: bottom sheet `translate 100% → 0` over 400 ms `cubic-bezier(.32,.72,0,1)`, grabber 36×5, rows 56 px 17 px labels, backdrop 40 % black; desktop centred card 16 px radius, scale .96 → 1 over 200 ms, version history `min(691px, 80vw)` radius 10. Privacy cards: `--surface`, radius 10, padding 30, 30 px key-colour icon, h3 15/600. Information: desktop 2 / 3 columns gap 20 / 24; phones inset grouped rows 44 px with hairlines.
- Plan code blocks introduced by `` `path`: `` are complete files; `` `path` (append): `` appends.
